# Playora instructions for Claude Code

Before coding, read AGENTS.md, docs/ENGINEERING_BASELINE.md, and .claude/skills/playora-engineering/SKILL.md.

The canonical React + TypeScript + Vite app shell is located at the repository root. The historical archives under bazi/ are not the app source of truth unless reviewed and explicitly promoted. Game logic, online multiplayer, registered accounts, backend persistence and production security controls remain unimplemented unless a later change proves otherwise.

Follow branch safety, modular architecture, security, Persian RTL, testing and evidence-backed delivery requirements in AGENTS.md and the Playora Engineering Skill. Do not modify main directly, do not claim unrun tests, and do not imply unfinished games are playable.

When reviewing another agent's work, independently inspect the diff and reproduce relevant behavior. Report confirmed findings with severity, file/line references, and test evidence.
